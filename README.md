# PTE 55 — Англи хэл

Анхан шатнаас **PTE Academic 55** оноо болон өдөр тутмын англи ярианд бэлтгэх вэб апп (утсанд суулгаж болно).

- 🏠 **Өнөөдөр** — өдөр бүрийн ~40 минутын төлөвлөгөө, streak
- 🧠 **Chunk** — 67 бэлэн хэллэг (ажлын талбай, Aussie яриа, эмч, банк...) зурагтай, карт (spaced repetition)
- 🗣️ **Shadowing** — 11 текст, өгүүлбэр бүрийг сонсох / удаан / дагаж хэлэх / яриа таних шалгалт
- 🎯 **PTE** — Read Aloud, Repeat Sentence, Describe Image, Retell Lecture, Answer Short Question, Respond to a Situation, Write From Dictation, Reading FIB, Essay/SWT загвар
- 📈 **Ахиц** — оноо, 4 долоо хоногийн идэвх, ярианы хурд

Build алхамгүй, цэвэр HTML/CSS/JS. Ахиц браузерын `localStorage`-д хадгалагдана.
Яриа таних нь Chrome / Edge (Android, компьютер) дээр хамгийн сайн ажиллана.

Локалаар ажиллуулах: `python3 -m http.server 8080` → http://localhost:8080
